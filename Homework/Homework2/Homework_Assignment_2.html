Notes about the dataset:

There are 5 different strain, environment, or (strain x environment) comparisons in the file:

yps606_wt_et_oh_response: log2(YPS606 ethanol stress / YPS606 unstressed), so positive values denote genes induced by ethanol stress and negative values denote genes repressed by ethanol stress.

yps606_msn2_4dd_et_oh_response: log2(YPS606 msn2/4∆∆ ethanol stress / YPS606 msn2/4∆∆ unstressed), and again positive values denote genes induced by ethanol stress and negative values denote genes repressed by ethanol stress.

wt_v_msn2_4dd_et_oh_response: log2( (YPS606 msn2/4∆∆ ethanol stress / YPS606 msn2/4∆∆ unstressed) / (YPS606 ethanol stress / YPS606 unstressed) ), so negative values denote genes with lower expression for the msn2/4∆∆ mutant’s ethanol response, and positive values denote genes with higher expression for msn2/4∆∆ mutant’s ethanol response. E.g., PGM2 has a logFC during the EtOH response of 7.60 in wild-type YPS606, but only 0.78 for the msn2/4∆∆ mutant’s EtOH response. The WT vs. mutant EtOH response comparison yields a logFC of -6.96, consistent with a diminished EtOH response in the mutant.

wt_v_msn2_4dd_unstressed: log2(YPS606 msn2/4∆∆ unstressed / YPS606 unstressed), so positive values denote genes with higher expression in the msn2/4∆∆ mutant under unstressed conditions, and negative values denote genes with lower expression in the msn2/4∆∆ mutant (note that the genes with the lowest expression in the msn2/4∆∆ mutant are MSN2 and MSN4, which makes sense since those two genes were deleted to create the mutant).

wt_v_msn2_4dd_et_oh_absolute: log2(YPS606 msn2/4∆∆ ethanol strss / YPS606 ethanol stress), so positive values denote genes with higher expression in the msn2/4∆∆ mutant under ethanol stress, and negative values denote genes with lower expression in the msn2/4∆∆ mutant ethanol stress (note that this is not the same as looking at the EtOH response comparison between strains. While many of the genes with lower expression in the msn2/4∆∆ mutant are induced by EtOH stress in the wild-type strain, this is not universally true (e.g., MRH1 has a logFC of 0.50 for the wild type ethanol response (not induced), but has -3.09 log2-fold lower expression in the msn2/4∆∆ mutant for this comparison).
