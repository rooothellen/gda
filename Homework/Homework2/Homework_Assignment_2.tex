\textbf{The Main Assignment:}

Using the ``02\_Gene\_Ontology.qmd'' exercise as a guide, answer the
questions below.

The 4\textsuperscript{th} and 5\textsuperscript{th} code chunks from
that qmd fileshould download a file with all of the gene expression data
for the comparison of wild-type yeast (YPS606) and the YPS606
\emph{msn2/4}∆∆ mutant, and then change the headers to remove the ∆
characters that certain packages don't recognize. The resulting file is
named ``DE\_genes\_Msn24\_EtOH.txt'' and in case you cannot generate
that file, it has also been uploaded onto OneDrive under Data Files
-\textgreater{} Msn24\_EtOH -\textgreater{} Differential\_Expression.
You can import the file directly into R Studio using the ``Import
Dataset'' in the upper right Environment section. Select ``From Text
(readr)\ldots{}'' from the dropdown menu, and click ``Browse\ldots{}''
to navigate your computer to select the file. Change the delimiter to
``Tab,'' and make sure ``First Row as Names'' is checked.~

If clusterProfiler is working, you'll be able to perform all of the GO
enrichment analysis in R. If not, you can still open
``DE\_genes\_Msn24\_EtOH.txt'' in Excel as a tab delimited text file and
then copy and paste gene lists into an online tool. For this exercise, I
would recommend the
\href{https://go.princeton.edu/cgi-bin/GOTermFinder}{Princeton GO Term
Finder}.

Notes about the dataset:

There are 5 different strain, environment, or (strain x environment)
comparisons in the file:

\textbf{yps606\_wt\_et\_oh\_response}: log\textsubscript{2}(YPS606
ethanol stress / YPS606 unstressed), so positive values denote genes
induced by ethanol stress and negative values denote genes repressed by
ethanol stress.

\textbf{yps606\_msn2\_4dd\_et\_oh\_response}:
log\textsubscript{2}(YPS606 \emph{msn2/4}∆∆ ethanol stress / YPS606
\emph{msn2/4}∆∆ unstressed), and again positive values denote genes
induced by ethanol stress and negative values denote genes repressed by
ethanol stress.

\textbf{wt\_v\_msn2\_4dd\_et\_oh\_response}: log\textsubscript{2}(
(YPS606 \emph{msn2/4}∆∆ ethanol stress / YPS606 \emph{msn2/4}∆∆
unstressed) / (YPS606 ethanol stress / YPS606 unstressed) ), so negative
values denote genes with lower expression for the \emph{msn2/4}∆∆
mutant's ethanol response, and positive values denote genes with higher
expression for \emph{msn2/4}∆∆ mutant's ethanol response. E.g.,
\emph{PGM2} has a logFC during the EtOH response of 7.60 in wild-type
YPS606, but only 0.78 for the \emph{msn2/4}∆∆ mutant's EtOH response.
The WT vs.~mutant EtOH response comparison yields a logFC of -6.96,
consistent with a diminished EtOH response in the mutant.

\textbf{wt\_v\_msn2\_4dd\_unstressed}: log\textsubscript{2}(YPS606
\emph{msn2/4}∆∆ unstressed / YPS606 unstressed), so positive values
denote genes with higher expression in the \emph{msn2/4}∆∆ mutant under
unstressed conditions, and negative values denote genes with lower
expression in the \emph{msn2/4}∆∆ mutant (note that the genes with the
lowest expression in the \emph{msn2/4∆∆} mutant are \emph{MSN2} and
\emph{MSN4,} which makes sense since those two genes were deleted to
create the mutant).

\textbf{wt\_v\_msn2\_4dd\_et\_oh\_absolute}: log\textsubscript{2}(YPS606
\emph{msn2/4}∆∆ ethanol strss / YPS606 ethanol stress), so positive
values denote genes with higher expression in the \emph{msn2/4}∆∆ mutant
under ethanol stress, and negative values denote genes with lower
expression in the \emph{msn2/4}∆∆ mutant ethanol stress (note that this
is not the same as looking at the EtOH response comparison between
strains. While many of the genes with lower expression in the
\emph{msn2/4}∆∆ mutant are induced by EtOH stress in the wild-type
strain, this is not universally true (e.g., \emph{MRH1} has a logFC of
0.50 for the wild type ethanol response (not induced), but has -3.09
log\textsubscript{2}-fold lower expression in the \emph{msn2/4}∆∆ mutant
for this comparison).
