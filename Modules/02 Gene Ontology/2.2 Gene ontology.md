## Gene ontologies
### Working with the output of genomic analysis
- Genomic analyses can return lists of hundreds of genes
- Common outputs from genomic analyses:
	- Differential expression, which returns a set of up- and down-regulated genes
	- Comparative genomic projects, which can return lists of genes present in one organism and absent in another
	- Genes positive for some regulatory element, like a particular transcription factor binding site in their promoter
	- Genes that have a phenotypic difference from the WT
	- Genes with certain physical properties, like: 
		- location on a chromosome
		- intron content
		- location relative to structural elements (telomeres, centromeres)
		- length
		- GC content
### Motivation for standardizing gene names
- As the genomes of model organisms were mapped, researchers began to understand that many organisms share genes but ==the lack of a common language for representing genes== limited the identification of homologs
	- e.g. Krebs cycle genes are highly conserved, but may may be named differently across organisms– the same gene might be referenced as a Krebs cycle gene, a TCA cycle gene, a metabolic gene, or a citric acid cycle gene
- **ontology**: a formal representation of concepts and the relationships between them
- **gene ontology**: a ==common language== for annotating and describing gene functions
	- Developed from a collection of model organism databases in 1998
	- Facilitates ==consistent annotation of gene products== both within and between organisms
	- Gene ontologies are now shared between all model organisms and some other common research subjects
- Gene ontologies allow us to make sense of a large dataset by identifying patterns of differential expression within a set of genes
- Goals of the [GO consortium](http://geneontology.org/):
	- Develop/maintain a controlled vocabulary for gene product attributes
	- Continuously annotate genes and gene products
	- Provide a database to access annotation data, and tools to enable functional interpretation

## Enrichment analysis
### Statistical tests for enrichment
#### Implementation: Hypergeometric distribution
*Where do these p-values come from?* 
The hypergeometric distribution is a probability distribution from statistics that is relevant here. In this case, we are looking at the probability of drawing a certain number of genes with a specific GO term in a list of DE genes, given the total number of genes in the genome.
Notice that the proteolysis term is identified as enriched among upregulated genes. Specifically, 137 DE genes have this GO term, where in the entire genome, there are only 5536 annotated genes. Of those, only 403 are annotated with the term "proteolysis". 

|            | Proteolysis genes | Whole genome | *total*   |
| ---------- | ----------------- | ------------ | ------- |
| DE genes   | 137               | 1,113        | *1,250*   |
| Background | 403               | 5,536        | *5939*    |
| *total*    | *540*             | *6,649*      | *7,189* |

*What are the odds that we see this by random chance?* Let's do the math:

```R
proteolysis_genes = 403

DE_genes = 1113

Overlap = 137

total = 5536 # number of genes in genome
```

```R
# Test for overrepresentation (enrichment)
phyper(q = Overlap-1, 
       m = DE_genes,
       n = total-DE_genes,
       k = proteolysis_genes,
       lower.tail = FALSE) # the probability that X > x
```

 `q = Overlap-1` because the `lower.tail = FALSE` argument tests without equality.

```R
# Test for underrepresentation (depletion)
phyper(q = Overlap, 
       m = DE_genes,
       n = total-DE_genes, 
       k = proteolysis_genes, 
       lower.tail = TRUE) 
```

As we see, there is strong evidence that the number of genes with this GO term is unlikely to be seen due to chance. In layman's terms, this GO term is enriched in upregulated genes in this contrast. The test for under-represenation shows there is no support for a hypothesis that this gene is underrepresented in the DE gene list.
#### Fisher's exact test
- **Fisher's exact test**: hypergeometric test; non-parametric statistical significance test used to determine if there are nonrandom associations between two categorical variables in a 2x2 contingency table
	- Classically used to define the number of successes in a sequence of *n* draws from a finite population without replacement
	- Calculates exact p-values
	- Assumes independence between observations

> [!equation] Fisher's exact test
> Where $k$ is the number of successes, $n$ is the number of draws made, $K$ is the number of total possible successes, and $N$ is total number of draws possible
> $$P(X = k) = \frac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}$$

> [!example] Classical example of Fisher's exact test: marbles
> Given a bag of 5 green marbles ($K$, number of total possible successes) and 45 red marbles, from which you may draw 10 times ($n$, number of draws made), what is the probability that exactly 4 ($k$, number of successes) of the marbles drawn are green?
> 
> |               | Drawn   | Not Drawn    | *total*  |
> | ------------- | ------- | ------------ | -------- |
> | Green Marbles | $k=4$   | $K-k=1$      | $K=5$    |
> | Red Marbles   | $n-k=6$ | $N+k-n-K=39$ | $N-K=45$ |
> | *total*       | $n=10$  | $N-n=40$     | $N=50$   |
> $$
> \begin{align*}
> P(X = 4) &= \frac{\binom{5}{4}\binom{45}{6}}{\binom{50}{10}} \\
> &= \frac{5 \times 8145060}{10272278170} \\
> &= 0.003964
> \end{align*}
> $$
> The probability that exactly 4 marbles are green is 0.3964%

- In the context of gene ontologies, Fisher's exact test is used to determine whether the number of genes in the differentially expressed set with a certain annotation is more, less, or is proportional to the number of genes in the genome with that annotation
- Additionally, genomic analyses are usually concerned with the cumulative probability ($X \geq k$) rather than the exact probability ($X = k$)
	- The cumulative probability gives the probability of seeing at least $k$ genes from that annotation differentially expressed

![[pdfVcdf.png]]

> [!example] Fisher's exact test for enrichment analysis
>|                                | Genes with a specific annotation | Genome  | *total* |
> | ------------------------------ | -------------------------------- | ------- | ------- |
> | Differentially expressed genes | 15                               | 33      | *48*    |
> | Genes in the genome            | 200                              | 7,000   | *7,200* |
> | *total*                        | *215*                            | *7,033* | *7,248* |
> - 15 genes isn't much compared to the size of the genome (7,000) or even set of differentially expressed genes (200)
> - However, 15 is approximately 50% of all the genes in the genome with that annotation, meaning that ~50% of all genes with that annotation were differentially expressed
> $$\begin{align*}
> P(X = k)  &= \frac{\binom{K}{k}\binom{N-K}{n-k}}{\binom{N}{n}}\\
> P(X = 15) &= \frac{\binom{48}{15}\binom{7248-48}{215-15}}{\binom{7248}{215}}\\
> & \dots \\
> P(X \geq 15) &= 1.9 \times 10^{-15}
> \end{align*}$$
> 
> The probability that there are 15 or more differentially expressed genes with this specific annotation, given their frequency in the genome, purely by chance is near zero
#### Implementation: Fisher's exact test
Interestingly, the hypergeometric distribution is the same thing as the Fisher's Exact test, so we can rerun the same tests above with a different command:

```R
# Fisher test for overrepresentation
fisher.test(matrix(c(Overlap, DE_genes-Overlap, proteolysis_genes-Overlap, total-DE_genes-proteolysis_genes + Overlap), 2, 2), alternative='greater')$p.value

# Fisher test for underrepresentation
fisher.test(matrix(c(Overlap, DE_genes-Overlap, proteolysis_genes-Overlap, total-DE_genes-proteolysis_genes + Overlap), 2, 2), alternative='less')$p.value
```

*How does the p-value that we get from this test compare to the results table?* They should match.
### Testing for enrichment with GO
- GO enrichment platforms/softwares preform an automated search for highly significant annotations automatically
	- Web platforms include [Princeton](https://go.princeton.edu/cgi-bin/GOTermFinder), [PantherDB](https://pantherdb.org/webservices/go/overrep.jsp), and [David](https://david.ncifcrf.gov/home.jsp)
	- R packages include `clusterProfiler`, `gprofiler2` and `topGO`
#### Accounting for multi-testing
- Since enrichment software searches for enrichment against 100,000+ GO terms, you must account for the impacts of multiple comparisons
	- **multiple comparisons problem**: the observation that preforming many statistical tests simultaneously on the same dataset drastically increases the false positive rate
	- Both the false discovery rate (FDR) and the Bonferroni correction are used to correct for this
- **false discovery rate**, FDR: the acceptable percentage of false positives returned by a statistical test
	- In practice, the FDR determines the acceptable percentage of false positive GO term enrichments, which is usually set to 5%
- **Bonferroni correction**: the practice of correcting for the effect of multiple comparisons by multiplying the p-values returned by the test by the number of tests run
	- When $n$ gets large (+1,000), the Bonferroni correction quickly creates a very conservative threshold for significance
- Both corrections assume independence, which is not treu for GO terms that are part of a nested hierarchy
	- Some programs collapse related terms to reduce the number of tests (and therefore the Bonferroni correlation)
	- `topGO` has an algorithm that applies FDR corrections while taking into account the dependency of related terms

### Create a Differentially Expressed (DE) Gene List
We need a list of differentially expressed genes to test for over (or under) enrichment of functional GO terms. Here, we choose genes with significantly ($\text{FDR} < 0.05$) higher expression ($\log{\text{FC}}>1$) in the EtOH treated wild-type cells compared to the unstressed wild-type control cells (positive values in the logFC column of WT EtOH response).

```R
# Subset data to just genes with significant fdr & log2FC
msn24_EtOH %>%
  filter(logFC_YPS606_WT_etoh_response > 1 & 
         fdr_YPS606_WT_EtOH_response < 0.05)
```

```R
#  Save results to a new variable:
DE_genes_upregulated_WT_EtOH <- msn24_EtOH %>%
  filter(logFC_YPS606_WT_etoh_response > 1 & 
         fdr_YPS606_WT_EtOH_response < 0.05) %>%
  pull(gene_id) 
```
### GO Term Enrichment Analysis
Now we have a list of genes (saved as `DE_genes_upregulated_WT_EtOH`) that we want to perform GO term enrichment on. We can do this using the clusterProfiler package's `enrichGO` function. This function takes a list of genes, an organism database, and the type of GO term (e.g., Biological Process, Cellular Component, Molecular Function) as arguments. We will use the `org.Sc.sgd.db` database, which is the annotation database for *Saccharomyces cerevisiae*.
#### Upregulated - GO Enrichments for Genes with Increased Expression in Ethanol Stress

```R
GO_WT_EtOH_up_results <- enrichGO(
  gene = DE_genes_upregulated_WT_EtOH,
  OrgDb = "org.Sc.sgd.db",
  # the universe argument defines the background
  universe = msn24_EtOH$gene_id, 
  keyType = "ORF",
  ont= "BP"
) %>%
  mutate(richFactor = Count / as.numeric(sub("/\\d+", "", BgRatio)))
```

Now, we can look at the results in table form.

```R
# Open up the results in a data frame to examine

```
#### Downregulated - GO Enrichments for Genes with Decreased Expression in Ethanol Stress

```R
# Create a list of genes to test for enrichment
DE_genes_downregulated_WT_EtOH <- msn24_EtOH %>%
  filter(logFC_YPS606_WT_etoh_response < -1 & 
         fdr_YPS606_WT_EtOH_response < 0.05) %>%
  pull(gene_id)

# Run GO enrichment analysis
GO_WT_EtOH_down_results <- enrichGO(
```
